# linas-project-2 — Kabankalan Catholic College landing page

A responsive, single-page landing page concept for Kabankalan Catholic College, Inc. The page presents the college's Catholic identity, educational pathways, campus life, and admissions information in a visual layout distinct from the source website.

The static site files are in `public/`. Start a local preview with:

```sh
python3 -m http.server 3000 --directory public
```
